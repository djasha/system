## Prompt

Draw a friendly cartoon lobster mascot as a flat SVG (200×150 viewBox): oval red body with darker segment lines, two big claws, thin antennae ending in dots, white eyes with dark pupils, and a small smile. Give every animatable part a class hook — .antL/.antR for antenna sway, .clawL/.clawR for snapping, .eyes for blinking, .pupil for cursor-follow — so GSAP recipes can target them without touching the artwork. Two reds only (bright + deep), matching the OpenClaw accent layer.

## Usage

- **Lobby appears ONLY on OpenClaw bundle surfaces.** The bundle theme enforces this: `.mascot-lobby` is display-none outside `.bundle-openclaw`.
- Ambient idle motion (bob, claw snap) is CSS; one-shot moments (entrance bounce, wave) use `lobWave()`/`heroEntrance()` from AutokitMotionRecipes.
- Keep Lobby near moments of success or greeting — he's a reward, not a watermark.

## Do / Don't

- **Do** wrap page placements in the `.mascot-lobby` class so theming can gate him.
- **Don't** put the lobster on Hermes or any non-OpenClaw product — that rule survives every redesign.
- **Don't** recolor Lobby per theme; if the bundle isn't lobster-red, it doesn't get the lobster.
